В данном репозитории, я реализовал веб-приложение погоды в выбраном городе с использованием API


Функционал:
1.Узнать погоду в любом городе (Как на русском, так и на Английском языках)
2.Отображение самой температуры в °C
3.Отобюражение описания погоды (На русском языке)
4.Использование динамических иконок погоды
5.Модальное окно погодой города
6.Работа с ошибками
