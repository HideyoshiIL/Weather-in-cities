В данном репозитории реализовано веб-приложение для просмотра погоды в выбранном городе с использованием API.

Изначально проект был разработан на чистом JavaScript. 
После изучения React приложение было полностью переработано: логика была перенесена в React-компоненты, добавлено управление состоянием и работа с React Hooks.

Функционал:

1. Поиск погоды в любом городе (поддержка русского и английского языков)
2. Отображение текущей температуры в °C
3. Отображение описания погодных условий на русском языке
4. Использование динамических иконок погоды
5. Модальное окно с подробной информацией о погоде
6. Обработка ошибок при запросах к API
7. Сохранение последних данных погоды в localStorage
8. Восстановление данных после перезагрузки
9. Автоматическое открытие модального окна при восстановлении

Используемые технологии:

- React
- JavaScript (ES6+)
- CSS3
- API OpenWeather
- React Hooks (useState, useEffect)
